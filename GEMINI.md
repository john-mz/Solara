# Contexto del proyecto (Gemini CLI)

Instrucciones breves para quien use **Gemini CLI** en este repositorio. El detalle normativo de commits y PRs está en `CONTRIBUTING.md`.

## Mensajes de commit

Si piden **generar, sugerir o revisar** un mensaje de commit (o un título de PR alineado a commits):

1. **Leer primero** `CONTRIBUTING.md` en la raíz del repositorio (sección de commits y, si aplica, PRs).
2. **Aplicar** el formato y tipos que definan ahí (p. ej. Conventional Commits, longitud de la primera línea, idioma, cuerpo con viñetas).
3. Si hace falta contexto del cambio, usar `git status` o el diff que compartan; no inventar alcance que no corresponda al working tree.

Si `CONTRIBUTING.md` no existiera o no cubriera commits, usar Conventional Commits en español, primera línea ≤72 caracteres, y cuerpo opcional con viñetas.
